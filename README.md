# Итоговый проект scheduler


## Описание проекта
Веб приложение для управления задачами с возможностью:
- Создания, редактирования и удаления задач
- Установки расписания задач с различным интервалом
- Поиск задач по дате или тексту
- Авторизация(опционально)


## Выполненные задания со звёздочкой
- Реализована возможность задать параметры порта и путь к БД из переменных окружения TODO_PORT и TODO_DBFILE соответственно
- Реализованы правила недельные и месячные правила повторения задач
- Реализована возможность поиска задач
- Реализована Аутентификация
- Добавлен Dockerfile


## Локальный запуск и тестирование
Переменные окружения для настройки проекта:
- TODO_PORT - порт на котором будет запускаться сервер
- TODO_DBFILE - путь к дб файлу sqlite
- TODO_PASSWORD - пароль авторизации. Чтобы отключить авторизацию достаточно указать пустой данную переменную.

Стандарные параметры запуска:
- Порт: 7540
- Путь к БД: ./scheduler.db
### Запуск локально
В корне проекта есть файл .env-file его можно использовать для конфигурации проекта переименовав его в .env
Проект при запуске автоматически читает переменные окружения из файла .env. Если он отсутствует используются значения, считанные из ваших переменных окружения.
При отсутствии .env файла и ваших переменных окружения запуск будет произведен на дефолтных значениях заданных в main.go
Для запуска проекта необходим установленный golang версии 1.24+
Запуск проекта:
```bash
go get .
go run main.go
```
### Сборка докер образа и запуск в докере
Для сборки и запуска докер образа необходим установить docker.
Сборка образа:
```bash
docker build -t scheduler .
```
В докер образе присутсвуют стандартные переменные окружения
```
ENV TODO_PORT=7540
ENV TODO_DBFILE=/data/scheduler.db
ENV TODO_PASSWORD=verysecretpassword
```
Переопределить их можно через флаг -e при запуске образа или передать файл с перемными окружения --env-file. Флаг -v для монитирования каталога с БД в файловую систему ПК.
Запуск докер образа, пример:
```bash
docker run --env-file ./.env-file -p 7540:7540  -v $(pwd)/db:/data scheduler:latest
```
### Запуск тестов
В каталоге tests, есть файл settings.go в нем описаны параметры для тестирования.
```go
var Port = 7540 // порт сервера переназначается из переменной окружения TODO_PORT
var DBFile = "../scheduler.db" // путь к бд перезначается из переменной окружения TODO_DBFILE
var FullNextDate = true // влючает тестирование недельного и месячного расписания
var Search = true // влючает тестирование поиска
var Token = `` // при использовании авторизации сюда необходимо указать JWT токен
```
Запуск тестов пример:
```bash
TODO_PORT=7540 TODO_DBFILE=/path/to/scheduler.db go test ./tests
```
